# CLAY ROOM · 3D 조각 공방

메시를 직접 밀고 깎고 다듬는 WebGL 2 조각 편집기입니다. 브러시 반경과 세기를 숫자로 입력하고, 대칭 조각·평탄화·주름·표면 다듬기와 실행 취소를 사용할 수 있습니다. 세분화는 기존 조각 형태를 보존하면서 정점을 추가합니다.

최대 8개 객체, 장면 전체 131072 정점 / 262144 삼각형. 시작 크기를 지정하고 덩어리를 추가·복사·선택·삭제할 수 있습니다. 각 객체의 조각·재질·변환을 따로 편집합니다. 부피 배율은 길이에 세제곱근으로 반영합니다. 실제 재질 밀도나 질량을 추정하지 않습니다. 편집은 float32 좌표에 반영되며 작은 수치 입력을 유지합니다.

축에 수직인 평면 또는 직접 입력한 법선/위치로 두 조각을 만들고, 닫힌 표면에서는 A/B 부피 비율로 평면을 찾습니다. 단면도 실제 삼각형으로 닫으며 최종 연결과 부피를 검사합니다. 분할은 별도 브라우저 worker에서 계산하며 취소 가능·20초 상한입니다. 열린/교차/복잡한 절단 경계는 원본을 유지하고 거절할 수 있습니다. ‘하나로 묶기’는 여러 메시를 같은 객체로 병합하는 기능이며 겹친 내부 면을 제거하는 불리언 합집합은 아닙니다. 자동 리토폴로지·전문 CAD 공차·프린팅 검증은 제공하지 않습니다.

처음에는 선택 도구입니다. 화면의 객체를 클릭하거나 오른쪽 목록에서 고르세요. 다른 객체를 브러시로 처음 클릭해도 선택만 바뀌며 조각하지 않습니다. 목록의 체크는 병합할 객체를 지정합니다. 방향키·WASD는 카메라 중심을 화면 방향으로 이동합니다. ‘중심 이동’ 도구의 드래그, 카메라 중심 XYZ/방향 버튼도 사용할 수 있습니다.

G 또는 ‘객체 이동’을 선택하면 드래그·방향키·WASD로 객체를 옮깁니다. 기본은 화면 평면이며 X/Y/Z로 세계 좌표 축을 고정하고 C로 화면 평면에 돌아갑니다. 키보드 간격은 0.0001–10m, Shift를 누르면 1/10입니다. 한 번의 드래그 또는 키를 누르는 동안의 이동은 실행 취소 한 번으로 복구되며 Esc는 진행 중인 이동을 취소합니다. V는 선택, F는 선택 객체에 화면 맞추기입니다. 조각 화면을 클릭해 키보드를 사용하며 글/숫자 입력·대화상자의 키는 가로채지 않습니다.

선택 테두리는 기본적으로 클릭·조작 후 잠깐만 보입니다. ‘선택 표시’에서 항상 표시/표시하지 않음, 0.25–3px 굵기와 농도를 바꿀 수 있습니다. 테두리가 없어도 선택 이름과 오른쪽 목록이 표시됩니다. 이 설정은 현재 페이지에만 적용되며 프로젝트 파일에는 저장하지 않습니다.

GLB는 모든 객체와 개별 재질·변환을 포함하며 1단위=1m입니다. STL은 모든 객체의 실제 변환된 삼각형을 mm로 변환합니다. PNG는 최대 4096×4096 실제 렌더링입니다. 선택 외곽선/절단 미리보기는 출력하지 않습니다. 버전2 프로젝트 JSON을 다시 열어 조각을 계속할 수 있고 버전1 단일 객체도 읽습니다. 기존 브라우저의 버전1 저장은 자동으로 불러오기만 할 때 덮어쓰지 않습니다. 사용자가 확인한 파일 교체·새 조각·편집은 버전2로 저장할 수 있으며, 불러온 원본 파일 자체는 수정하지 않습니다.

자동저장은 이 브라우저의 자체 키만 사용합니다. 3.5MB를 넘으면 파일로 저장하세요. 기존/다른 앱 기록은 읽지 않습니다. 입력 파일은 최대 24MB입니다. 백엔드와 계정이 없습니다.
