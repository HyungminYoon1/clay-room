# Decisions

## D08 — Independent materials for split objects (2026-10-13)

Context: acceptSplit spread the original object into A and B, sharing the mutable material object. Editing A's color/roughness immediately changed B; serialization later separated references but did not restore the lost appearance. Options: repair references during UI edits, clone entire geometry again, or copy material at the model's split boundary. Decision: each accepted piece gets its own material record; retain existing independent mesh outputs and identity transforms. Rationale: per-object editing must preserve the other piece without extra geometry allocation or schema migration. Affected: scene-model, scene regression tests, index/objects.css practice panel, tools/verify-browser.mjs. Review: the regression first failed, then passed with file roundtrip and undo/redo; actual worker split, two separate colors, camera/object/pointer routing, mesh preservation, GLB materials/STL world coordinates and 4K PNG. No quality, object/resource budget, provider or persistence-key change. Arbitrary self-intersection repair and printing guarantees remain unsupported.

## D07 — Smooth keyboard motion and visible mode return (2026-10-10)

Context: the user finds camera return after G unclear and requests smooth arrows/WASD for both camera and objects. Options: retain OS repeat, enable unrelated OrbitControls damping (which does not smooth object translation), or add a shared pure elapsed-time target model with an app RAF adapter. Decision: SmoothKeys ignores duplicate keydowns, targets one exact interval for a tap and ramps held input after100ms to20 intervals/sec. Normalize continuous diagonal direction.40ms exponential smoothing and release settling up to250ms distribute steps without indefinite drift. Cap elapsed increments at50ms; Shift scales target/future hold input to1/10. Preserve finite transforms, whole-scene history and one commit per continuous interaction. Explicit completion flushes pending target displacement; Escape clears it and restores the original object scene. Focus/lifecycle/modifiers/mode changes cancel RAF and held-key state; never encode/save on each frame.

G now toggles move/select, V returns to camera keys, and the move strip has a direct return button; top text identifies the keyboard target. Keep render/picking in viewport and DOM/RAF/persistence in app; no new dependency/storage/server or geometry/schema change. Rationale: prevent OS repeat cadence and initial step jumps while keeping precise taps and creative focus. Affected: interaction-model/app, index, tests, architecture/requirements/README/verification and one WEB LAB actual preview. Review: repeated frame samples for both modes, release stop, Shift tap precision, one undo/redo, Escape, held-mode changes, text/dialog/blur protection,30/60/144 FPS pure integration, real multi-object pointer regression and1440/390/320. Physical keyboard latency, all GPUs/browsers and every old app remain NOT_RUN.

## D06 — Quiet selection and explicit object movement (2026-10-10)

Context: the user requests camera arrows/WASD, click selection, mouse/keyboard object movement and unobtrusive configurable selection frames. Options: retain default sculpting, reuse arrows ambiguously across modes, add unbounded movement/gizmo state, or separate select/camera/object move. Decision: default select, first click on another object is selection-only even with a brush. G activates object move; V selects; F fits. Unmodified directions pan camera outside move mode and translate objects inside it. X/Y/Z lock world axes, C returns to the screen plane. Explicit keyboard interval0.0001–10m and Shift tenth-step; pointer translation intersects a fixed view plane or projects onto the locked axis, with a view-parallel fallback. Direction-preserving clipping keeps positions inside±100. Pointer drag/held movement share one bounded whole-scene undo snapshot, Escape cancels, lifecycle blur finishes; inputs/modals/composition/modifiers do not leak to canvas shortcuts.

Selection uses a subtle900ms gesture flash and stays visible during manipulation, or an explicit always/hidden choice. Selected name and list remain identifiable. Locally pinned LineSegments2/LineMaterial supports true0.25–3 CSS-pixel width rather than an ineffective WebGL basic linewidth setting; opacity0.05–1. Reuse a fixed12-edge buffer. All display preferences stay page-memory only; keep the existing own storage key, project versions, mesh/history budgets and file formats. PNG and GLB/STL exclude all helpers. Rationale: preserve creative focus and avoid accidental deformation/history spam or data migration. Affected: interaction-model, app/viewport, UI/CSS, pinned vendor entry/build, tests, architecture/requirements/README/verification, one WEB LAB real preview/metadata. Review: actual camera/key routing, multi-object pointer selection/drag, precise axis movement, grouped undo/cancel/lifecycle, text/dialog protection, transient/hidden/width rendering, helper-free PNG and unchanged geometry/other keys,1440/390/320. Physical input hardware and all GPUs remain NOT_RUN.

## D05 — User-approved bounded multi-object scene (2026-10-10)

Context: the user requests multiple lumps, size/copy/merge/split and camera movement; the architecture explicitly limited the project to one object. Work on that boundary paused and the user explicitly approved changing it. Options: retain one object, add unlimited objects and history, or use a bounded scene with per-object geometry. Decision: version2, max8 objects and combined131072 vertices/262144 triangles, existing20-snapshot/48MB history budget for the entire scene. Keep the same own key, actual UTF-8 3.5MB autosave and24MB import bounds. Read v1 into memory without overwriting it on opening; the next deliberate edit/file replacement may save v2. Unknown/corrupt data is preserved. Rotations permit±3600°, positions remain±100 and positive scales0.001–100. No shared state or DB.

For splitting choose actual clipping/capped surfaces, not hidden/duplicated whole geometry. Earcut3.0.2 from the pinned local Three package triangulates holes, with its exact ISC notice. Plane normals may be arbitrary. Ratio splitting bisects geometric volume, not assumed real mass. Validate closed consistent input and both outputs, preserve total volume, bound cut edges4096/search20 steps and run a cancellable20s worker. Failed/cancelled jobs leave the scene intact; changes/exports are blocked during a job. Options rejected: unbounded dense CSG/voxel remeshing or falsely labeling mesh concatenation as a watertight union. Merge concatenates transformed geometry using the first material and explicitly retains internal overlap. GLB keeps separate objects/materials; STL exports every transformed triangle, both exclude editor helpers.

Rationale: object count alone does not bound CPU, GPU buffers, topology, export size or undo memory. The browser performs WebGL rendering and geometry work, but explicit app budgets are still needed. Preserve layer separation: scene/cut pure models, rendering/picking/camera in viewport, DOM and own-key state in app, local-only worker. Affected: scene/cut/worker, mesh validation, viewport/app, object UI/CSS, vendor build, license, README/architecture/requirements and tests. Review: v1 roundtrip, eight/global limits, independent copies and all-scene undo, oblique/ratio/hole cuts, volume and connectivity, real multi-object exports, cancellation, storage denial/other keys, camera and320/390/1440 input. Independent CAD/printing and all GPU hardware NOT_RUN.

## D01 — actual mesh, bounded resources (2026-10-09)

Context: sculpting must retain small edits in an exportable object. Options: shader deformation, voxel engine, indexed mesh brushes. Decision: welded float32 triangle mesh, local adjacency and true vertex displacement; 131072 vertices/262144 triangles and 48 MB history. Rationale: precise edits and standard exports on free static hosting. Files: mesh-model, viewport, app. Review: exported vertices, undo, normals, degeneracies and frame cost. Self-intersection repair/remeshing deferred, not claimed.

## D02 — project storage and file boundary

Options: shared WEB LAB schema, cloud files, independent browser/project files. Decision: own key only, 3.5 MB autosave / 24 MB imported JSON cap, verify readback, preserve malformed data, require explicit replace. Rationale: no migration, costs or exposure of creative files. Files: app, model, README. Review: quota failures, oversized/high-resolution files and re-import.

## D03 — geometry formats and units

Decision: pinned Three.js 0.186.1 with GLTFExporter and STLExporter; same-origin vendor with MIT license. GLB meters, STL numeric millimeters stated in UI, editable JSON separate. 4K PNG renders the actual scene at the requested pixel count with resource limits and cleanup. Options rejected: cosmetic downloadable placeholders or silent lower resolutions. Files: viewport, vendor tools, export UI. Review: headers, triangle counts, bounding boxes, actual PNG dimensions. No printability warranty.

## D04 — UI font and local-only assets

Unmodified Pretendard Variable 1.3.9, SIL OFL 1.1, full license supplied. No remote media or content-generated portraits. The first object is an original procedural folded pebble, editable with every tool. Files: assets/fonts, model demo, CSS. Review: same-origin assets and actual browser preview.
